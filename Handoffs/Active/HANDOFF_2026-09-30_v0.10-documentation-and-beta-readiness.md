### Python Tooling & Unity Pipeline Probing
When the Unity Editor is running in the background with `com.unity.pipeline` active on port 7800:
- Python probe scripts (such as `pipeline_client.py` or MCP clients) can communicate directly with the Editor Pipeline Server:
  - `python3 pipeline_client.py cmd get_performance_stats` — retrieves live draw calls, batches, and frame times.
  - `python3 pipeline_client.py cmd console_status` — queries console errors and warnings.
  - `python3 pipeline_client.py eval "<expression>"` — evaluates C# expressions in the running scene.
- Pipeline MCP tools (`mcp__unity__editor_status`, `mcp__unity__console_status`) provide native agent hooks into the same service.
