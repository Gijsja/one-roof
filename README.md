# One Roof — Unity Agent Handoff Pack

Drop this directory's contents into the root of the Unity repository. `AGENTS.md` is the entry point for every coding or content agent.

## Start here

1. Read `AGENTS.md`.
2. Read `Docs/01_GAME_VISION.md` and `Docs/02_ARCHITECTURE.md`.
3. Select one unblocked task from `Planning/BACKLOG.md`.
4. Before Unity work, follow `Docs/10_DEVELOPMENT_WORKFLOW.md` for isolated headless compilation and validation.
5. Create a handoff from `Handoffs/HANDOFF_TEMPLATE.md` before ending work.

This pack defines the project; it does not create the Unity project or choose a source-control host.
