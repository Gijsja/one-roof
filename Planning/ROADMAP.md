# Roadmap

## M0 — Repository and project foundation

Unity project, source control, packages, assembly definitions, CI compile/test, Bootstrap, and coding conventions.

## M1 — Tower kernel

Grid/floor model, rooms and portals, build commands, content catalog, versioned save envelope, and debug visualization.

## M2 — Vertical movement proof

Walk graph, stairs, elevator state machine, trip requests, route planning, wait metrics, and deterministic tests.

## M3 — Living first playable

Fifty residents, households, home/work/food schedules, visible pooled NPCs, simulation speed, and save/load.

## M4 — Understand and respond

Build/Inspect/Data modes, elevator overlay, placement prediction, second-elevator intervention, and golden acceptance test.

## M5 — Beta systems

Businesses, broader utilities, satisfaction, relationships, factions, events, eight overlays, blueprints, progression, and content expansion.

Each milestone exits only when its acceptance evidence is recorded in a handoff and its tests pass.
